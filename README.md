By [Izaan Ullah Asad](https://linkedin.com/in/izaan-ullah-asad-6943b4283) — BS Cybersecurity, FAST-NUCES Karachi. Microsoft security stack: Sentinel, Defender XDR, KQL.

---

## What you'll find here

Each writeup answers the same four questions, because those are the questions a SOC actually cares about:

1. **What fired, and what did the raw telemetry look like?**
2. **How was it scoped** — what else was touched, over what window?
3. **What was the verdict**, and what evidence supports it?
4. **What would I change** so this is detected earlier or with less noise next time?

Walkthroughs that stop at "I found the flag" are not included. The reasoning is the point.
